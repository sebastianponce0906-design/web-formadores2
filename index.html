Administración

Perfil administrador: puede dar de alta y clasificar usuarios, ver todos los documentos, consultar todos los registros, modificar desplegables, tarifas y los campos adicionales de las fichas. Perfil staff: sólo consulta. Perfil formador: sólo gestiona lo suyo.

1. Alta de usuario

Primero se rellenan todos los datos de alta. Debajo aparece el listado editable de usuarios. El usuario se genera automáticamente con nombre + primer apellido en minúsculas y la contraseña temporal con iniciales + número correlativo.

2. Usuarios dados de alta

El administrador puede corregir los datos en la propia tabla y pulsar Guardar. También puede dar de baja a formadores o staff indicando fecha de baja. La tabla no se sale de la ventana: si hay muchas columnas, se desplaza horizontalmente dentro de la caja.

3. Desplegables maestros

Los cambios se aplican a las fichas nuevas. Los programas incluyen siglas para generar el código interno de cada conferencia.

4. Tarifas aplicables por campaña/programa

Los campos principales de las fichas quedan fijos para no romper las exportaciones. Aquí administración puede añadir, editar, activar/desactivar o quitar campos adicionales visibles en la ficha del formador o en la ficha de conferencia.
